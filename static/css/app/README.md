# 스타일시트

예전 `static/css/style.css`(약 32,000줄)를 **원래 순서 그대로** 13개로 나눈 조각입니다.
`templates/index.html`에서 번호 순서대로 로드되므로 스타일 적용 결과(캐스케이드)는 분리 전과 같습니다.

원본 CSS가 기능별로 모여 있지 않고 곳곳에 흩어져 있었기 때문에, 파일 이름은 각 조각의 첫 섹션을
가리킬 뿐 그 기능의 스타일이 모두 그 파일에 있는 것은 아닙니다. 기능별 재배치는 화면 확인과 함께
조금씩 진행해야 합니다.

- 순서를 바꾸거나 파일 사이로 규칙을 옮길 때는 같은 선택자를 덮어쓰는 뒤쪽 규칙이 있는지 먼저 확인하세요.
- 분리하면서 짝이 맞지 않던 `}`와 떠 있던 속성 3군데를 지웠습니다. 그 때문에 그동안 무시되던
  `.mcc-wr-pct`, `.mcc-wr-bar-track`, `.td-bar-col:hover .td-bar-fill` 규칙이 이제 적용됩니다.
